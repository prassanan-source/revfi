☁️ Cloud Infrastructure Cost Modeling
Monthly AWS/GCP infrastructure cost estimates at four customer scale tiers. Assumes a multi-tenant SaaS architecture with AI features (Claude API calls for back-office automation), PostgreSQL data layer, and standard web-tier components.

Architecture assumptions: Karyva.AI is a multi-tenant SaaS platform where each customer (a business — restaurant, accounting firm, grocer, etc.) uploads receipts, invoices, payroll data, and transaction records. The AI layer (Claude API or equivalent) processes documents, categorizes expenses, flags anomalies, and generates P&L summaries. Data is stored per-tenant in a shared PostgreSQL database with row-level isolation. A worker queue handles async AI jobs (document OCR, classification, report generation).

Key variables: Each customer generates roughly 50–200 AI API calls/month (document processing + queries), stores ~500MB–2GB of data/year, and makes ~500–2,000 app requests/month. These estimates use AWS US-East pricing (September 2026 rates) and assume Claude Haiku 4.5 for routine tasks (~$0.80/M input tokens) and Sonnet for complex jobs (~$3/M input tokens).
